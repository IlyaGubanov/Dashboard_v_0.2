## Методика

После fetch сверены GitHub branches и `git ls-remote --heads origin`. Для каждого ref выполнены
`git merge-base`, `git rev-list --left-right --count origin/main...REF`,
`git merge-base --is-ancestor REF origin/main`; для не-предков — `git cherry` и diff от merge-base.
Для двух merge-only вершин дополнительно сравнены tree SHA родителей и их включение в main.
Критерий C означает включение по ancestry либо отдельно подтверждённую эквивалентность содержимого.
Разность всего дерева с современной main не означает уникальную разработку: это может быть отставание.
