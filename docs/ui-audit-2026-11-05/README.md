## Исходное состояние и область

Первая модернизация уже стала частью продукта: официальный знак, фирменные поверхности, настройки администратора, обе темы, таблицы и мобильный выбор вкладок направлений работают. После неё добавлены самостоятельные карта/РЭБ, кадры с должностями, движениями и ФОТ, экономика с ДДС и отклонениями, видео, причины отставания, панорамы и новые редакторы. Основные проблемы этой итерации — неудобство длинных форм и неоднородность новых разделов, а не отсутствие оформления вообще.

Рабочий сайт открыт в браузере до реализации; пользователь самостоятельно авторизовал сеанс. Осмотрены сводка, кадры, РЭБ, благоустройство, экономика и карта; светлая/тёмная темы и мобильный размер. На production использовались только навигация и локальное отображение. Его финансовые/кадровые сведения не копировались в репозиторий. Production не использовался для проверки записи или доработок.

У production нет доступного маркера SHA: визуальное совпадение не доказывает идентичность сборок. В рабочем кадровом меню не было вкладки «Должности», которая есть в dev; отсутствие ФОТ при локальном скрытии финансов не трактуется как отсутствие функции. Экономика, ДДС, отклонения, единая карта, РЭБ и причины отставания уже наблюдались в production. Подтверждённое сравнение версий кода выполнено по истории Git после первого аудита.

Все локальные изменения и записи — в новой тестовой БД, созданной миграциями и штатным демо-наполнением, с отдельными API/файлами. Для полного серверного набора дополнительно создан отдельный MySQL с семью одноразовыми БД. Чужие worktree и реальные БД не изменялись.

На начало работы открытых PR поиск GitHub не вернул. Однако вне dev остаются два уникальных коммита: `mvsst-10 / 3fdc97f` (сверка техники и детализация плиток), `mvsst-11 / 4b7ce8a` (ввод причин отставания). Они не интегрировались и не считаются покрытыми этой проверкой. Пересечения: `EntryTab.tsx`, `FleetPage.tsx`, `theme.css`, `DelayReasonSettings.tsx`, инструкции. При последующей интеграции сохранить обе стороны и повторить UI-проверки.

## Ограничения и отдельные предложения

1. Все разделы текущей dev просмотрены, но **не выполнен полный цикл записи во всех 52 декларациях окон** и не перебраны все комбинации прав/состояний. Нет гарантии для произвольного производственного объёма данных.
2. Реальные регистраторы/камеры и потоковое видео, экранный диктор, физические iOS/Android/клавиатура/safe area, установка PWA, полный WCAG 2.2 AA и нативная полоса вкладок остаются непроверенными. Смена пароля и реальных прав не выполнялась; не все виды импорта/выгрузки пройдены через UI.
3. Локальный переключатель «Финансы скрыты» не скрывает содержимое экономики. Это наблюдавшееся до изменений несоответствие области действия; требуется отдельное решение по поведению. Серверные права финансов не менялись, переключатель не является механизмом авторизации.
4. Сверка техники/детализация плиток из mvsst-10 и изменение причин из mvsst-11 не входят в проверенную dev. После их интеграции нужны повторные проверки пересекающихся экранов.
5. Виртуализация очень больших реестров, сохранённые фильтры, массовые операции и изменение финансовых/производственных правил — отдельные продуктовые задачи.

PR передаётся для проверки; merge, deploy, подключение к production-БД и изменение конфигурации рабочих серверов не выполнялись.
