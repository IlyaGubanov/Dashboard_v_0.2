# 09. Прогнозы, «Мои задачи», ввод с телефона (этап 9б)

## Прогноз завершения

Отвечает на вопрос «успеем ли к сроку при нынешнем темпе».

```
темп      = (готовность сейчас − готовность ~4 недели назад) / число дней
завершение = дата среза + (100 % − готовность сейчас) / темп
отклонение = завершение − плановое окончание
```

- Базовая точка — отчётная точка не ближе 28 дней до среза; если истории меньше — самая ранняя не ближе 7 дней.
- Плановое окончание объекта — его дата окончания, а если её нет — дата самой поздней позиции. У направления — самый поздний объект.
- Для Школ готовность берётся в долях от суммы весов видов работ.
- Для направлений «по отчётам» (Благоустройство) прогноз не строится: там нет непрерывного ряда.

| Состояние | Когда | Вид |
|---|---|---|
| в срок | завершение не позже плана | ◎ дата · в срок |
| опаздывает | завершение позже плана | ⏱ дата · +N дней (оранжевый до 30 дней, красный — больше) |
| темпа нет | прирост меньше 0,1 п.п. в неделю или завершение дальше 3 лет | ⏸ темпа нет |
| выполнено | готовность ≥ 99,5 % | ✓ |
| — | меньше двух точек с фактом | нет данных |

Наведите на прогноз — подсказка покажет темп, с какой даты он считается и плановое окончание.

**Где видно:** колонка «Прогноз» в реестре объектов (сортировка ставит опаздывающих наверх, есть в выгрузке CSV),
шапка карточки объекта, карточка направления в сводке («Прогноз завершения … · не успевают N объектов»),
показатель «Объектов, не успевающих к сроку по прогнозу» в конструкторе направлений.

Прогноз — оценка по прошлому темпу, а не обещание: после ускорения или простоя он меняется уже со следующей недели.

## «Мои задачи»

Колокольчик в шапке и блок на главной. Число на колокольчике — задачи «пора сделать» и «срок прошёл»; красный — есть просроченное.
Щелчок по задаче открывает нужную вкладку с нужным отбором.

| Кому | Задача | Уровень |
|---|---|---|
| Ответственный за ввод, куратор | «Внести факт за неделю с …: не внесено N объектов из M» (по последней открытой точке) | к сведению до дня плана (среда), «пора» — в день плана, «срок прошёл» — через 2 дня |
| Исполнитель | «Устранить замечания: N, из них просрочено K» — назначенные ему и без исполнителя на его объектах | «пора», при просроченных — «срок прошёл» |
| Куратор; автор замечания | «Проверить устранение: N замечаний» | «пора» |
| Куратор | «Открыть неделю с …» — если точки текущей недели нет | «пора» |
| Куратор | «Проверить и закрыть прошлые недели» — открытые точки прошлых недель | к сведению |

Задачи считаются из текущих данных при каждом запросе (раз в 5 минут и сразу после сохранения), отдельно не хранятся.
Администратор и руководство получают задачи только как авторы замечаний — общая картина у них в сводке.

**Не сделано:** рассылка напоминаний на почту или в мессенджер. Для почты нужен адрес SMTP-сервера организации
и учётная запись отправителя; когда они будут — это отдельная небольшая доработка (ежедневное письмо с теми же задачами).

## Ввод с телефона

На экранах уже 768 px вкладка «Ввод данных» перестраивается:

- позиции — карточками: крупные поля, статус списком, кнопки готовности **−5 / +5 / +10 / 100%**, примечание — по нажатию;
- на телефоне цифровая клавиатура открывается сразу (поле числа);
- раскрыт только первый объект, содержимое свёрнутых не рисуется — лист из 40 объектов и 300 позиций не тормозит;
- кнопка **«Сохранить · N»** во всю ширину внизу экрана; несохранённые поля подсвечены, при уходе со страницы — предупреждение.

Фото к замечаниям — кнопкой «Сделать фото» (сразу камера), см. [08-zamechaniya-i-faily.md](08-zamechaniya-i-faily.md).

### Установка на экран телефона

Приложение можно добавить на главный экран как обычное: Android (Chrome) — меню → «Установить приложение»;
iPhone (Safari) — «Поделиться» → «На экран „Домой“». Открывается без адресной строки, со своим значком.
Работает только при наличии связи (офлайн-ввод не предусмотрен).

|---|---|---|

Прогноз приходит в существующих ответах: `forecast` у строк `/directions/:code/sites` и карточки объекта,

## Проверено

- 16 сквозных проверок: прогноз у всех объектов МКД, совпадение реестра и карточки, сводка, нет прогноза у «отчётных» направлений
  и на первую точку, плитка конструктора; задачи Петровой и Соколова совпадают с данными; «устранено» уменьшает задачу
  исполнителя и увеличивает задачу проверяющего; внесённый факт уменьшает «не внесено»; без входа — 401.
- Модульные тесты прогноза (опоздание, в срок, темпа нет, мало данных, без плана).
- В браузере: колокольчик и «Мои задачи» под куратором, переход сразу в отбор «На проверке»; колонка прогноза и сортировка;
  ввод на телефоне 375 px — карточки, кнопки, нижняя панель сохранения, без горизонтальной прокрутки.
