# Видеонаблюдение: проверяемые требования

Ветка `codex/school-video`, база `3d15a28`. Существующие незавершённые правки исходного checkout не включаются.

Вопрос экрана: что происходит на выбранных объектах прямо сейчас? Прямой эфир отделён от отчётных дат. По умолчанию четыре камеры, на телефоне одна; остальные подключаются по выбору.

Фиксированный QA-набор: школа с 12 камерами, другая школа с 2; отключённая камера; отдельно архивная камера; выключенный регистратор; пользователь без видео; пользователь только первой школы; источник H.265. Ожидания: максимум 4 активных потока на desktop, 1 на 375 px; недоступный объект не раскрывает метаданные/плейлисты/сегменты; архив не включается при восстановлении регистратора; H.265 не объявляется универсально совместимым.

Поставка: Prisma migration, shared schemas, grant policy, encrypted credentials, protected nginx media route, on-demand MediaMTX reconciliation, player lifecycle, admin CRUD/archive/diagnostics, docs, tests and screenshots. Real Dahua/production changes excluded.
