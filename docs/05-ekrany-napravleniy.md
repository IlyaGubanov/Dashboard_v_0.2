# Экраны направления (этапы 6а и 6б)

Код: [apps/web/src/pages/DirectionPage.tsx](../apps/web/src/pages/DirectionPage.tsx) и [pages/direction](../apps/web/src/pages/direction).
Экраны общие для всех направлений: что показывать, решают данные (есть ли план, деньги, люди, замечания, надстройки).

## Адрес страницы

`/d/<направление>?tab=…&date=…&site=…` — вкладка, дата среза и открытая карточка объекта хранятся в адресе:
ссылку можно отправить коллеге, кнопка «Назад» работает.

| Параметр | Значения |
|---|---|
| `tab` | `overview`, `sites`, `matrix`, `schedule`, `trackers`, `dynamics`, `map`, `people`, `settings` |
| `date` | ГГГГ-ММ-ДД — срез на прошлую дату (последняя отчётная точка не позже даты); нет — последняя точка |
| `site` | id объекта — открытая карточка |

## Вкладки

| Вкладка | Что на ней |
|---|---|
| **Обзор** | готовность против плана, отклонение, состояние, изменение к прошлой точке, отметка «не проверено куратором»; объекты, отстают, критично, выполнено, люди, техника, деньги, доп. показатели; распределение объектов по состоянию; таблица по разделам/лотам; отстающие объекты (щелчок — карточка) |
| **Объекты** | реестр: поиск по объекту и куратору, фильтр по разделу и состоянию, сортировка по любому столбцу, выгрузка в Excel (CSV) того, что отфильтровано |
| **Динамика** | готовность (факт и план), люди, техника, освоение (КС-2, оплачено) по отчётным точкам; каждая мера — отдельный график; переключатель «Таблица» |
| **Устройство направления** | кураторы и ответственные (с областью прав), правила расчёта, виды работ, разделы, статусы, доп. поля, надстройки |

## Карточка объекта

Открывается поверх страницы (из реестра, обзора, сводки).

| Раздел | Что в нём |
|---|---|
| Шапка | готовность против плана на дату, состояние, сроки, стоимость, КС-2, оплачено, люди/техника, замечания, просроченные позиции |
| Работы | позиции: статус, факт, план на дату, значок «срок прошёл», объём факт/проект, стоимость, КС-2/оплачено, сроки, ответственный, **когда и кем внесено** |
| Паспорт и ответственные | адрес, округ, подрядчик, проектировщик, лимит, координаты; куратор, ответственный за ввод, прорабы с контактами; доп. поля направления по группам |
| Динамика | готовность объекта по отчётным точкам |
| Надстройки | Школы — закупки (оплата → поставка → монтаж), индивидуальные испытания, МГЭ; Сети — документация |
| Договоры | номер, подрядчик, даты, сумма, аванс |

## API (добавлено)

| Запрос | Что отдаёт |
|---|---|
| `GET /api/directions/:code/dynamics?date=` | точки динамики направления до даты: факт, план, люди, техника, КС-2, оплачено, проверено ли |
| `GET /api/directions/:code/sites/:id?date=` | карточка объекта целиком |

## Этап 6б

| Вкладка | Что на ней | Когда показывается |
|---|---|---|
| **Матрица** | объекты × виды работ (по группам): цвет — состояние по графику и порогам направления, число — прежний средний процент; красная точка — срок прошёл. При нескольких позициях цвет задаёт наиболее проблемная неисключённая работа: критично → отставание → нет данных/графика → в графике/выполнено → не начато. Подсказка объясняет состояние, план и объёмы; щелчок по ячейке открывает карточку объекта сразу на этой работе; фильтры по разделу и «только отстающие» сохранены | всегда |
| **График работ** | диаграмма Ганта: полоса — срок, заливка — выполнение (цвет — состояние), линия — дата плана, красная обводка — срок прошёл; «по объектам» (раскрываются работы) или «по видам работ» | если есть плановые сроки |
| **Надстройки** | по каждой надстройке: средняя готовность этапов; таблица «позиция × объект» или «объект × этап». Завершение — зелёное, незавершённый этап с прошедшей плановой датой — предупреждение, будущий срок и отсутствие данных — нейтральные. Собственные подписи и цвета статусов сохранены; дата сама по себе не означает завершение. Список просрочек использует те же состояния, что ячейки | если надстройки заведены |
| **Карта** | объекты на карте (OpenLayers): цвет — выполнено / в работе, размер — число замечаний (из отчёта или незакрытых в приложении); наведение — название, состояние, готовность; щелчок — карточка; линейка масштаба; список объектов без координат | если у объектов есть координаты |
| **Ответственные** | роль и область прав, назначения на объекты, позиции, число записей, последний ввод; **контроль заполнения** — кто внёс данные в текущую отчётную точку | всегда |

API: `GET /api/directions/:code/grid?date=` (позиции всех объектов), `/trackers` (надстройки по всем объектам), `/people` (ответственные и контроль заполнения).

Карта — на OpenLayers (`apps/web/src/pages/direction/olSitesMap.ts`). Библиотека подгружается только при открытии вкладки
«Карта» и в основной пакет интерфейса не входит.

Подложка карты — OpenStreetMap. Для своего сервера тайлов: при сборке веба — `VITE_MAP_TILES` (и `VITE_MAP_ATTRIBUTION`),
в `.env` сервера — `MAP_TILES_HOST` (иначе политика безопасности страниц не пустит картинки).
Правила OpenStreetMap допускают умеренное использование с указанием авторства; при большой нагрузке нужен свой сервер тайлов.
