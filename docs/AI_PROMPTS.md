# Короткие промпты для работы с ИИ

AGENTS.md в корне — единая инструкция. Она находится в main и dev; CLAUDE.md и инструкции
Copilot ссылаются на неё. В новом чате лучше явно попросить прочитать файлы: не все инструменты
загружают их автоматически. Промпты ниже можно копировать; заменить только текст в квадратных скобках.

## Новая задача

```text
Работаем с репозиторием IlyaGubanov/Dashboard_v_0.2.
Сначала прочитай AGENTS.md и CLAUDE.md, проверь ветку, status и worktrees.
Создай отдельную свободную mvsst-N от свежей origin/dev.
Задача: [что нужно сделать].
Выполни задачу, проверь результат, отправь коммиты и создай PR в dev.
Main и серверы не обновляй. В конце дай ссылку на PR и результаты проверок.
```

## Продолжить существующую задачу

```text
Репозиторий: IlyaGubanov/Dashboard_v_0.2. Продолжаем [ветка или ссылка на PR].
Прочитай AGENTS.md и CLAUDE.md, проверь текущие изменения и состояние PR.
Убедись, что в этой ветке сейчас не работает другой исполнитель.
Осталось сделать: [что осталось]. Продолжи эту задачу, сохрани чужие изменения.
Проверь результат и обнови PR в dev. Main и серверы не обновляй.
```

## Объединить готовую работу в dev

```text
В Dashboard_v_0.2 прочитай AGENTS.md и проверь PR [ссылка или номер].
Проверь состав изменений и результаты тестов. Если работа готова, объедини PR в dev
merge-коммитом. Отдельное формальное согласование владельца не требуется.
Если есть конкретная проблема, сообщи её. Main и серверы не обновляй.
В конце сообщи SHA dev и результат CI.
```

## Перенести проверенную dev в main

```text
В Dashboard_v_0.2 прочитай AGENTS.md. Поручаю перенести проверенную dev в main.
Сначала проверь полный состав изменений и CI, чтобы не захватить постороннюю работу.
Если всё готово, создай и объедини PR dev → main merge-коммитом, затем синхронизируй
историю main обратно в dev по GIT_WORKFLOW.md. Серверы и деплой не трогай.
Сообщи ссылки на PR, итоговые SHA и результаты проверок.
```

Если нужен другой сценарий, укажите его прямо: какую ветку использовать, можно ли объединять
изменения и требуется ли деплой. Задача «написать код» сама по себе не поручает обновлять production.
