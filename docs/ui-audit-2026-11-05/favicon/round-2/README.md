# Favicon — второй раунд

Предыдущая библиотечная пиктограмма отклонена пользователем. Эти шесть авторских геометрических концепций подготовлены только для выбора; ресурсы приложения в этом раунде не изменялись.

[Сравнительный лист](comparison.png) · [HTML 1:1](comparison.html)

Знаки построены вручную как полноценные SVG, без геометрии Tabler/Lucide. В тёмной теме меняется контрастная пара корпоративных цветов через prefers-color-scheme, а не силуэт. В PNG экспортированы обе темы в 16/32/48/160 px. Макеты вкладок иллюстративные; это не скриншоты нативной полосы браузера. Лист снят Edge при deviceScaleFactor=1.

1. **М / русло** — Две опоры образуют «М». Между ними — открытое русло: организация, строительство и вода в одном знаке. Самая прямая связь с названием. Хорошо сохраняет рисунок при 16 px. [SVG](01-ruslo.svg)

2. **Сечение** — Массивный разомкнутый контур и проходящий через него водный канал. Образ сечения сооружения, без букв. Строгий технический характер. Угловой силуэт и боковой выход отличают его от обычного щита. [SVG](02-sechenie.svg)

3. **Квартал** — Неравные строительные блоки очерчивают квартал. Негативное пространство образует проходящую через него улицу. Сдержанный знак для реестров и городской инфраструктуры. Более абстрактный и менее именной. [SVG](03-kvartal.svg)

4. **Связь** — Два угловых маршрута переплетаются и продолжаются дальше. Узел объединяет направления, людей и сведения. Выразительный собственный ритм. Меньше буквальных ассоциаций; зазор в центре важен при 16 px. [SVG](04-svyaz.svg)

5. **Створ** — Две наклонные опоры формируют проём. Центральный просвет напоминает перспективу инженерного прохода. Самый лаконичный силуэт. Сильная строительная ассоциация; связь с водой выражена слабее. [SVG](05-stvor.svg)

6. **Исток** — Цельный водный силуэт рассечён прямым инженерным проходом. Природная форма встречается с точной конструкцией. Самая явная связь с водной средой. При малом размере сильнее напоминает отраслевой, чем аналитический знак. [SVG](06-istok.svg)

Предварительный приоритет для обсуждения: 1 — связь с названием; 2 — инженерная выразительность; 4 — собственный абстрактный характер. Это дизайнерская оценка, не проверка узнаваемости на сотрудниках. Проверка юридической уникальности и реестр товарных знаков не проводились.

Окончательный вариант, ICO, подключение и синхронизация PWA будут подготовлены после выбора пользователя.
