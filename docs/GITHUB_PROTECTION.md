# Права GitHub и договорённости команды

Команда выбрала простой процесс на доверии: правила для ИИ находятся в [AGENTS.md](../AGENTS.md),
сценарии — в [GIT_WORKFLOW.md](GIT_WORKFLOW.md), стартовые промпты — в [AI_PROMPTS.md](AI_PROMPTS.md).

Включать branch protection, обязательные approvals, CODEOWNERS, required checks или менять default
branch для этого процесса не нужно. Участники сохраняют свои права на коммиты и ветки.
ИИ следует инструкциям, а конкретное поручение пользователя определяет его задачу и полномочия.
CI оставлен для проверки качества; workflow, запрещавший направления PR, и шаблоны жёсткой защиты удалены.

Это заменяет прежнюю рекомендацию включить административную защиту. Исторический аудит
[GIT_AUDIT_2026-11-01.md](GIT_AUDIT_2026-11-01.md) сохранён как снимок прошлого состояния,
а не инструкция к включению ограничений. Настройки доступа GitHub этим изменением не меняются.

Файл в репозитории помогает модели увидеть правила, но не гарантирует поведения каждой модели.
В новом чате явно просить прочитать AGENTS.md; перед merge проверять итог и результаты тестов.
