# 07. Конструктор направлений (этап 8)

Новое направление (парки, поликлиники, дороги…) собирается администратором из настроек, без программирования.
Меню: **Администрирование → Конструктор направлений** (только роль ADMIN).

## Что настраивается

| Вкладка | Что задаёт | Ограничения |
|---|---|---|
| **Основное** | название, краткое имя, код (латиницей, в адресе страницы; после создания не меняется), значок, цвет, как называть объекты; отчётные точки (день / неделя / отчёт), день плана недели (по умолчанию среда), формула готовности, метод плана, источник денег и подпись стоимости, подпись готовности в сводке, пороги «отставание / критично», «только просмотр», вкл/выкл | «Критично» должно быть строже «отставания». Выключенное направление пропадает из меню и сводки, данные сохраняются |
| **Статусы** | статусы позиций (с флагами «считается выполненным», «не учитывать», «итоговый») и статусы объектов; порядок, цвет | Используемый статус удалить нельзя — сервер ответит, сколько записей на нём |
| **Доп. поля** | поля паспорта объекта и позиции: строка, текст, число, деньги, процент, дата, да/нет, выбор из списка, несколько из списка, ссылка; единица, группа, обязательность | Для «выбора из списка» нужны варианты. Убранное поле уходит в архив, значения на объектах сохраняются |
| **Надстройки** | таблицы «строки × этапы» на каждом объекте (закупки, испытания, согласования) или «карточка» — одна строка с полями-этапами. Тип значения этапа: процент, число, да/нет, статус из списка (с отметкой завершённых), дата, текст. Строки можно вставить списком: `Название; категория; ед.` | Этап, по которому уже внесены значения, удалить нельзя. Убранные строки уходят в архив |
| **Показатели сводки** | до 6 плиток под готовностью в карточке направления: метрика из каталога + подпись + параметры (статусы, единица, надстройка и этап) | Параметры проверяются по справочникам направления |
| **Плитки обзора** | плитки на вкладке «Обзор» направления: показывать или скрыть, порядок, своя подпись, цвет (смысловой или свой код). Вид, размеры и общие цвета плиток — «Оформление», см. [13-oformlenie.md](13-oformlenie.md) | Пусто — все плитки в обычном порядке |

Пороги светофора направлений в сводке руководства (по умолчанию −2 / −10 п.п.) — на странице списка направлений.

## Новое направление

1. **Новое направление** → заполнить форму. Поле «Создать по образцу» копирует статусы, доп. поля, надстройки,
   виды работ и показатели сводки выбранного направления. Объекты, факт и люди не копируются.
   Без образца направление получает три статуса позиций: «Не начато», «В работе», «Выполнено».
2. Настроить вкладки редактора.
3. **Пользователи и роли** — назначить куратора и ответственных за ввод.
4. Куратор на вкладке **Управление** направления заводит разделы, виды работ, подрядчиков и объекты,
   на вкладке **Ввод** открывает первую неделю и вносит факт.

## API (только ADMIN)

| Метод | Путь | Назначение |
|---|---|---|
| GET / POST | `/api/admin/directions` | список / создать (`copyFrom` — код образца) |
| GET / PATCH | `/api/admin/directions/:code` | всё устройство направления / основные настройки |
| PUT | `/api/admin/directions/:code/statuses` | `{ entity, items }` — полный список статусов сущности |
| PUT | `/api/admin/directions/:code/fields` | `{ entity, items }` — полный список полей сущности |
| PUT | `/api/admin/directions/:code/trackers/:tracker` | создать или заменить надстройку |
| PUT | `/api/admin/directions/:code/kpis` | показатели сводки |
| GET | `/api/admin/metrics` | каталог метрик |
| GET / PUT | `/api/admin/settings/overview` | пороги сводки руководства |

Каждое изменение пишется в журнал (до / после). Каталог метрик (`packages/shared/src/admin.ts`) и их реализация
(`apps/api/src/kpi/metrics.ts`) сверяются тестом `metrics.spec.ts`: новую метрику нужно добавить в оба места.

## Проверено

- API: 25 сквозных проверок — «Парки» по образцу МКД, свои статусы, поля, надстройка «Озеленение», показатели;
  куратор заводит парк, открывает неделю, вносит 20 % — направление со своими плитками появляется в сводке;
  запреты (используемый статус, этап со значениями, неверные параметры, чужая роль → 403).
- Интерфейс: список, создание (ошибки у полей), все вкладки редактора, сохранение показателей, надстройки
  (добавление строк списком), доп. поля.
